# Анализатор журналов событий (CLI)

## Реализованный функционал
* Построчное чтение файла (без загрузки в память).
* Фильтрация по времени (от включительно, до исключительно), уровню и источнику.
* Подсчет ошибок с указанием номеров строк.
* Сохранение в JSON или CSV.

## Примеры запуска
1. Общая статистика:
python3 main.py --input test.log

2. Только ошибки в JSON:
python3 main.py --input test.log --level ERROR --format json --output report.json

3. Фильтр по источнику и времени:
python3 main.py --input test.log --source auth-service --from 2024-05-01T12:00:00Z --to 2024-05-01T13:00:00Z

## Тестирование
Запуск с HTML-отчетом:
pytest --cov=. --cov-report=html test_main.py
